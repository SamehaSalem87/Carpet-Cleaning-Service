Carpet Cleaning Service
About the Project

This is a simple C# console application for Islam's Carpet Cleaning Service.

The program asks the user how many small and large carpets they want to clean. It then calculates the cleaning cost, sales tax, and total price.

What I Learned

While working on this project, I practiced:

Getting user input with Console.ReadLine().
Converting input into numbers using int.Parse().
Using variables to store prices and quantities.
Performing calculations with arithmetic operators.
Calculating sales tax and the final price.
Displaying results using Console.WriteLine().
